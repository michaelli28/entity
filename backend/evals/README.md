# Golden Behavioral Evals

20 golden behavioral evals with binary rubric covering the ZStar AI mentor's core response patterns across categories: TAM analysis, traction probing, team assessment, moat skepticism, GTM specificity, scope enforcement, safety (crisis signals and jailbreak resistance), product sense, fundraising coaching, and pivot signal discrimination. Run with `uv run python evals/run_evals.py` from the `backend/` directory. Requires `ANTHROPIC_API_KEY` to be set in the environment. Target: ≥16/20 pass rate before the mentor prompt is considered shippable.

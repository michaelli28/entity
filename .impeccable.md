# ZStar — Impeccable Design Context

This file governs all design decisions for ZStar. It is read before any design work.

## Design Context

### Users

Founders at any stage — pre-idea, pre-seed, post-revenue — usually working in the cracks of a long day: early morning before the team is up, late night after the household is down, between calls. They arrive tired and unsure, with a tangled list of things competing for the next hour of attention.

They are **grinding**. The job to be done is not "look at charts." It is: *make the next move obvious*. A good session ends with the founder **clearer and energized to work** — not praised, not educated, not entertained. The mentor is a peer-reviewer for decisions, not a cheerleader.

The product is consumed on laptops (primary) and phones (secondary, in bed or in transit). It is used alone. It is used often. It earns its place by being the thing that replaces doom-scrolling founder Twitter at 11pm.

### Brand Personality

**Sharp. Sleek. Dynamic.**

- **Sharp** — precise language, precise typography, precise numbers. No hedging. No fluff copy. The interface has an opinion.
- **Sleek** — restraint. Tinted monochrome, generous negative space, one accent. Nothing is ornamental for its own sake.
- **Dynamic** — motion marks state changes and reveals. Scroll-linked moments on marketing surfaces. In-app, motion is rare and purposeful — a signal, not a texture.

Emotional target when leaving a session: *"I know what I'm doing next hour."*

### Aesthetic Direction

**Refined dark — editorial-technical hybrid.** The lineage is Linear (monochrome discipline, token-first system, precision spacing), Dedalus Labs (atmospheric dark with one strong accent, scroll-linked reveals, large display type), and Formless (editorial rhythm, expressive italic display breaking into precise sans body).

**Theme:** Dark only for v1. The context (late-night grinding, laptop-centric) locks it.

**Palette (OKLCH, purple-tinted monochrome with rare vivid violet accent):**

```
--bg:              oklch(0.13 0.012 290);   /* violet-tinted near-black, not #000 */
--bg-elevated:     oklch(0.17 0.018 290);   /* sheets, popovers */
--surface:         oklch(0.21 0.022 288);   /* cards when needed */
--border:          oklch(0.28 0.020 290);   /* hairlines, 1px only */
--border-strong:   oklch(0.38 0.025 290);

--text:            oklch(0.96 0.005 290);   /* not pure white */
--text-muted:      oklch(0.72 0.010 290);
--text-dim:        oklch(0.52 0.015 290);

--accent:          oklch(0.68 0.22 295);    /* vivid violet — THE 10% */
--accent-soft:     oklch(0.42 0.15 295);    /* hover/pressed states */
--accent-glow:     oklch(0.68 0.22 295 / 0.18);  /* for rare motion moments */

--signal-pos:      oklch(0.74 0.14 160);    /* green-leaning, muted */
--signal-warn:     oklch(0.78 0.14 75);     /* amber, muted */
--signal-neg:      oklch(0.66 0.18 25);     /* red, muted */
```

Neutrals are tinted toward violet (chroma 0.01–0.025) — imperceptible as color, perceptible as cohesion. Pure black and pure white never appear.

**Typography:**

- **Body & UI:** `Geist Sans` (OFL, Vercel). Precision neo-grotesque. Not in the reflex list. Handles 11px → 80px gracefully.
- **Data & metadata:** `Geist Mono` — used ONLY for actual numeric data (scores, deltas, signal IDs, timestamps, eyebrow labels). Never for "technical vibes" decoration.
- **Display accent:** `Bodoni Moda` (Google Fonts, OFL). Modern didone with dramatic contrast strokes and a true italic. Reserved for expressive moments — hero display type, pull-quotes, section markers, single-word emphasis. Not on the reflex list.
- **Scale:** Fixed `rem` scale in-app. Fluid `clamp()` on marketing surfaces. 5 steps, ≥1.25 ratio.
- **Hierarchy cue:** Weight + size contrast, family contrast (sans/serif). Never gradient fill. Never all-caps body.

**References**

- [linear.app](https://linear.app) — token discipline, spacing rhythm, restraint, nav pattern
- [dedaluslabs.ai](https://dedaluslabs.ai) — atmospheric dark, scroll-linked background graphics, display-scale typography
- [formless.xyz](https://formless.xyz) — editorial rhythm, italic display breaking precision sans

**Anti-references**

- Not a crypto dashboard (no neon cyan-on-black, no glow-for-glow's-sake)
- Not a Notion/Linear clone — we share discipline, not identity
- Not an AI tool template (no purple→blue gradient text, no shimmer borders, no "intelligent" pulsing orbs)
- Not a founder-bro SaaS landing (no rotating logos, no "as seen in" stripes without substance)

### Design Principles

1. **Chat is the product; chrome recedes.** The conversation surface carries the weight. Navigation, sidebars, and surrounding UI fade to near-background when a mentor session is active. Founder attention is sacred.

2. **Signal over polish.** Every pixel earns its place by revealing state, enabling an action, or reinforcing hierarchy. Decoration that doesn't do work gets cut. No sparklines as ornament. No icons-above-every-heading.

3. **Data-grade precision.** Scores, signals, and numeric state render with typographic discipline — tabular figures, consistent decimals, semantic color only where the number's direction matters. Numbers are truth; treat them that way.

4. **Earned motion.** One well-orchestrated arrival (hero reveal, chat-opens, score-computes) beats ten continuous micro-fidgets. Scroll-linked moments on marketing. In-app motion is rare and informative — state changes, entrances, feedback. Never decorative loops.

5. **Quiet dark.** Violet-tinted neutrals, one vivid accent used rarely, hairline borders. The interface is a black-tie room, not a nightclub. Impact comes from contrast and restraint, not luminance.

### Accessibility

- **WCAG 2.2 AA** minimum on all surfaces.
- Body text contrast ≥ 4.5:1 (the `--text` on `--bg` pairing clears this comfortably). Muted text ≥ 4.5:1 against its own background — verify, don't assume.
- Focus rings: always visible, 2px `--accent` with 2px offset. Never removed, never relying on color alone.
- `prefers-reduced-motion: reduce` disables scroll-linked, staggered, and parallax motion. State-change feedback (button press, toast arrival) reduces to opacity-only.
- Tap targets ≥ 44×44px on touch surfaces.
- Dark-only is a deliberate choice; document it in settings so screen-reader users are never surprised.

### Absolute bans (inherited from impeccable, reaffirmed here)

- No `border-left` / `border-right` > 1px as colored accent stripes on cards, list items, callouts, or alerts.
- No `background-clip: text` with gradient fill. Ever.
- No glassmorphism used decoratively. Blur only when it reveals hierarchy (modal backdrop over working context).
- No purple→blue gradient hero text.
- No pulsing "AI is thinking" orbs. Use a typographic cursor or honest progress instead.
